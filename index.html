THE PROCESS

How Dijkstra's Algorithm Works

The algorithm repeatedly selects the unvisited node with the smallest known distance.

01

Initialize

Set the source distance to 0 and every other node's distance to infinity.

02

Select

Select the unvisited node with the smallest tentative distance.

03

Update

Check its neighbors and update their distances when a cheaper route is found.

04

Reconstruct

Repeat until the destination is reached, then trace previous nodes to display the route.

ALGORITHM DETAILS

The Logic Behind the Route

This implementation follows the basic Dijkstra approach described in our project report.

Pseudocode

DIJKSTRA(graph, source, destination)

1. Set distance[source] = 0
2. Set all other distances = infinity
3. Mark all nodes as unvisited

4. While an unvisited node exists:
   a. Select the node with minimum distance
   b. Mark the node as visited
   c. For each unvisited neighbor:
      newDistance = currentDistance + edgeCost
      If newDistance is smaller:
          Update distance
          Store previous node

5. Reconstruct path from destination
   using previous nodes

6. Display path and total cost

Complexity Analysis

Time Complexity O(V²)

Basic implementation that repeatedly searches for the unvisited node with minimum distance.

Space Complexity O(V²)

For an adjacency-matrix graph representation, along with distance and visited arrays.

V = number of vertices (network devices).
